# Position Trading Framework 🎯

یک چارچوب عامل‌محور مبتنی بر ماشین وضعیت (Agentic State-Machine Framework) برای پیاده‌سازی گام‌به‌گام و منضبط استراتژی پوزیشن تریدینگ با هوش مصنوعی.

---

## 💡 فلسفه و معماری (Architecture & Philosophy)

بزرگترین چالش استفاده از مدل‌های زبانی (LLM) در مدیریت معاملات، حاشیه‌پردازی و ارائه حجم زیادی از داده‌های متنی غیرعملیاتی (Wall of Text) است. این ریپازیتوری هوش مصنوعی را در قالب یک **ماشین وضعیت قطعی (Deterministic State-Machine Wizard)** مقید می‌کند:

1. **یک گام، یک سوال**: ایجنت در هر گام فقط و فقط یک سوال مطرح می‌کند.
2. **مرجع واحد حقیقت (`state.json`)**: تمام تصمیمات، بودجه‌ها، سطوح ورود و وضعیت‌ها در یک فایل جیسون نگهداری و همگام‌سازی می‌شوند.
3. **ساختار ماژولار فازها (`phases/`)**: تفکیک وظایف از راه‌اندازی تا پایش مداوم هفتگی.
4. **پیکربندی منعطف بازارها (`markets/`)**: ساختار سه‌لایه‌ای اثبات‌شده (Core 50% / Growth 20% / Reserve 30%).

## 📁 ساختار مخزن (Repository Structure)

```text
position-trading-framework/
├── AGENT.md                     # پرامپت هسته، قوانین حاکم و جدول مسیریابی ایجنت
├── state.json                   # پایگاه داده وضعیت فعلی (Single Source of Truth)
├── README.md                    # مستندات و راهنمای راه‌اندازی
│
├── markets/                     # الگوهای پیش‌فرض بازارهای مختلف
│   ├── crypto_spot.json         # بازار اسپات کریپتو (BTC, ETH, SOL, LINK, USDT/USDC)
│   ├── commodities_global.json  # کامودیتی‌های جهانی (طلا، نفت، نقره و ذخیره دلاری)
│   └── iran_rial.json           # بازار ریالی (گواهی شمش طلا، صندوق طلا، درآمد ثابت)
│
└── phases/                      # جریان‌های کاری ماژولار فازها
    ├── 01_onboarding.md         # فاز ۱: انتخاب بازار، بودجه، واچ‌لیست و پله‌های ورود
    ├── 02_macro_deep_search.md  # فاز ۲: تولید پرامپت جستجوی کلان و ارزیابی رژیم بازار
    ├── 03_technical_levels.md   # فاز ۳: تعیین سطوح چارت، محاسبه اردرهای لیمیت و حد بی‌اعتباری
    └── 04_weekly_autopilot.md   # فاز ۴: اتوپایلوت پایش هفتگی و ممیزی پوزیشن‌ها
```

## 🚀 نحوه شروع به کار (Quickstart)

برای آغاز فرآیند تعاملی، کافیست هر هوش مصنوعی توانمند (مانند Gemini، Claude یا ChatGPT با دسترسی به فایل‌ها) را به این ریپازیتوری متصل کرده و پیام زیر را ارسال کنید:

```text
Read AGENT.md and start.
```

یا به فارسی:
```text
فایل AGENT.md را بخوان و شروع کن.
```

ایجنت بلافاصله `state.json` را بررسی کرده، مرحله فعلی را تشخیص می‌دهد و نخستین سوال متمرکز را از شما خواهد پرسید.
